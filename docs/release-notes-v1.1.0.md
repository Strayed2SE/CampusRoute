# v1.1.0-public

## 多线程下载/上传聚合加速

本版本新增路由器端“按连接分配”的国内流量聚合加速：

- 默认关闭，启用后才采样和安装加速选择规则；
- 以校园网单方向封顶速度为基准，满足带宽、活动连接数和新连接频率条件后，从 10% USB 分流起步，最高默认 50%；
- 只处理 `ctstate NEW` 且没有策略 mark/connmark 的国内 TCP/UDP 连接；
- 已建立连接保留原出口，不做逐包跨接口发送，因此不会因步进调节而重置下载；
- USB 或校园网无可用默认路由、健康探测失败、或加速后端缺失时，自动降级为 0%，基础策略分流和阻断逻辑保持不变；
- IPv4/IPv6 独立统计，排除 DNS、NTP、门户、私网和插件接管流量；
- LuCI 增加基础设置、高级阈值和实时状态字段。

Windows 端在本版本保持现有行为；新版公开 Windows 包仅为便于统一发布而重新命名。

## 兼容与限制

需要 QWRT/OpenWrt 的 legacy iptables、`xt_statistic`、`xt_conntrack` 和 conntrack 统计接口。缺少任一能力时，WebUI 显示降级原因，但原有国内/海外分流仍可用。

该功能是连接级流量分配，不是逐包链路捆绑。不同学校的 Dr.COM 门户仍需按本地抓包结果填写，公开包不包含任何真实账号、密码、令牌或现场地址。
